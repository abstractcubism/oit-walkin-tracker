# Rutgers logo files

`rutgers-logo.svg` is the official Office of Information Technology horizontal unit signature
(RUOIT, RED and BLACK, SVG) from the Rutgers signature generator, unedited. Every screen shows it at
the top, 36 px tall or more (the digital minimum), with clear space of a quarter of its height on every
side, as the Rutgers Visual Identity System User Guide requires.

- Don't edit, recolor, crop or redraw it. To replace it, download a new file from
  https://signaturegenerator.rutgers.edu and save it under the same name.
- It sits on light backgrounds only (white or cream). On a dark or red background you would need the
  RED_WHITE or WHITE version instead.
- If you swap in a file that says something else, change `BRAND_ALT` in `public/common.js` to match,
  so screen readers say what the logo says.

If the file is ever missing, pages show "Rutgers University" in plain text where the logo goes.
